- Vision sidecar health check — **implemented** through the registry-backed
  `vision_health` port; multi-tenant health probes must discover it from the
  registry rather than assume internal port 8088.
- SSH agent — no port is allocated. The SSH harness uses `SSH_AUTH_SOCK`, a Unix
  socket, so it does not need a registry slot.
- Open decision — allocate another range in the 30000s or use an external
  reverse proxy such as Traefik.
