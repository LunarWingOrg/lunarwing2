# LunarWing release cadence
## Odd numbers
### focus more on
* bug fixes
* security improvements
* polishing
## Even numbers
### focus more on
* Feature releases
## Major Releases
* Contain very large changes or a very large amount of changes
### An example of a MAJOR RELEASE is 1.1.0
#### The 2.0.x line is the current MAJOR RELEASE series (2.0.0 shipped after 1.1.9.0; active work targets 2.0.4.0)
