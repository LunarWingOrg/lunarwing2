# LunarWing release cadence
## Odd numbers
### focus more on
* bug fixes
* security improvements
* polishing
## Even numbers
### focus more on
* Feature releases
## Major Releases
* Contain very large changes or a very large amount of changes
### An example of a MAJOR RELEASE is 1.1.0
#### 2.0.0 was the most recent MAJOR RELEASE; we are currently in the 2.0.x line (e.g. 2.0.4)
