## Scope

Test every external worker (pebble, opencode, opencode2, kimi) on a fresh
multi-tenant tenant, with worker images built **with toolchains**
(Rust/Go/C++/Python/Node in-image). Drive long-running, complex jobs through
the tenant daemon's `job_create` builtin tool that exercise the workers' own
tools: Python, Rust, and C compiles/runs inside the worker containers.

Host: Gentoo dev VM, systemd (user-manager tenant units), podman rootless
per-tenant stores, 12 cores / 23 GiB RAM.

## Setup record

- Tenant: `extworktest`, created 2026-10-05 via
  `mt-admin add-tenant extworktest --docker-group --no-ssh --no-weechat-bootstrap --no-health --with-pebble --with-opencode --with-kimi --with-opencode2 --llm-api-key <reused from tenant antelope> --llm-base-url http://cotterhomelab3.netbird.selfhosted:3000/openai/v1`
- Tenant checkout: this branch (mt-admin clones the current checkout's branch).
- Pebble NanoGPT key: reused from tenant antelope's `pebble.env` via
  `mt-admin configure-pebble extworktest --nanogpt-api-key <key>` (never printed).
- Build: `mt-admin build-tenant extworktest --with-pebble --with-opencode --with-kimi --with-opencode2 --with-toolchains`

## Test design

Per worker, driven through the tenant's web gateway chat
(`POST /api/chat/send` on a fresh thread) instructing the tenant agent to call
`job_create` with `mode: <worker>`, `wait: false`:

1. **gauntlet** (primary): write+compile+run a C program (gcc -O2, 300x300
   matrix multiply), create+build+run a Rust cargo project (naive fib(35)),
   write+run a Python 3 script that parses both outputs into report.json,
   optional Go run, then write SUMMARY.md and list the workspace.
2. **smoke** (fallback/diagnostic): write smoke.txt and cat it back.

Jobs polled via `GET /api/jobs` / `/api/jobs/{id}`; artifacts collected via
`/api/jobs/{id}/events` and `/api/jobs/{id}/files/{list,read}`. Tool approvals
answered with `always` via `POST /api/chat/approval`.
