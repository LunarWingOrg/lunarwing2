## Issues found & fixed along the way

1. **ENGINE_V2 steer gap (FIXED in code).** Item 3 shipped `/steer` for the
   legacy loop only. Under the tenant default (`ENGINE_V2=true`) a mid-turn
   `/steer <note>` fell through the engine-v2 routing block into the legacy
   dispatcher, which answered "Nothing is running right now" while an engine
   thread was actively running — a silent drop with a misleading message.
   Fix: `bridge::handle_steer` + routing arm injects the note into the scoped
   running engine thread via `ThreadManager::inject_message`, with the exact
   same mid-turn framing the legacy loop wraps (`wrap_steer_note` shared
   between the classic loop and the bridge) and identical acknowledgement
   texts. Regression tests mirror the scoped-interrupt scaffolding.
   Commit: `03fa6f7ab`.

2. **mt-admin add-tenant silently half-clones from a shallow SOURCE_REPO
   (FIXED).** When the fleet source checkout is shallow (this machine's
   `/home/rarity/lunarwing2_gitlab` is shallow since 2026-08-31 14:06,
   created by branch-prep automation), `clone_tenant_repo`'s plain
   `git fetch origin` aborts with "did not send all necessary objects", the
   checkout error is swallowed behind `tail -1`, and add-tenant leaves an
   unusable half-clone (`No commits yet`, no `ic/`). Fix: `clone_tenant_repo`
   probes `git rev-parse --is-shallow-repository` on SOURCE_REPO and switches
   both clone paths to `--depth=10000` transfers. Commit `3f0a81b7b`.
   Workaround used ahead of the fix: manual depth-bounded in-place clone.
