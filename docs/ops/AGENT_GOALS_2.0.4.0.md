This single root cause explains ALL of item #12's listed failures at once: python-syntax, registry-json, shell-syntax, and version-policy all run in `.lint-job`'s pinned python image (the exact digest in the error), and wasm-channel-test-artifacts runs in `.rust-job`'s pinned rust image — both docker.io.
