## CI failure and repair

Pipeline [#4708](https://git.lunarwing.org/lunarwing/lunarwing2/-/pipelines/4708)
failed required `rust-check-libsql`
[#86164](https://git.lunarwing.org/lunarwing/lunarwing2/-/jobs/86164) on the
`laptop` runner. Rustup could not resolve `static.rust-lang.org` while fetching
the Rust 1.96.1 channel manifest; compilation had not begun.

There was also a bootstrap defect: the pinned Rust image's published config
(`sha256:55c395291aeff1aadcfe3f4cb4238a3ffd2e36388c74a4638febbe7688892fb8`)
installs `--profile minimal`. Rustup creates `rustfmt`/`cargo-clippy` proxy
executables even without those components. The old `command -v` checks therefore
skipped installation, leaving `ic/rust-toolchain.toml` to trigger an implicit,
un-retried download inside the Cargo command.

`bootstrap-rust.sh` now calls `ensure-rust-components.sh` to probe actual
components with `rustup run 1.96.1 ... --version`, install only missing ones,
and verify each installation. Installation has at most three attempts and
5s/10s backoff. Exhaustion or an unusable component fails bootstrap; the exact
compiler-version check and all required compilation/test gates remain enforced.
Persistent DNS/HTTPS failures still require runner repair.
