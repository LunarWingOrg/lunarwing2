## Why no temporary tenant was created

WI#95 is an in-process type-conversion defect with no service, database,
channel, or tenant configuration component. A live provider cannot reliably be
made to return each terminal condition, especially `content_filter`; it would
exercise the same adapter less deterministically than the committed fake
provider. The focused tests inject `Length` and `ToolUse` directly across the
production bridge boundary, and the canonical conversion tests cover all five
protocol spellings. A temporary tenant would add teardown risk without adding
coverage for the defect described by WI#95.
